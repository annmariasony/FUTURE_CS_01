# OWASP ZAP Vulnerability Assessment

This repository contains the work completed for Future Interns – Cyber Security Internship Task 1.

## Project Objective

To perform a vulnerability assessment on a web application using OWASP ZAP, identify security vulnerabilities, analyze their potential impact, and recommend appropriate mitigation measures.

## Target Website

- demo.testfire.net (Test Website)

## Tools Used

- OWASP ZAP
- Google Chrome
- GitHub
- Canva

## Key Findings

- Cross-Site Scripting (DOM Based)
- Absence of Anti-CSRF Tokens
- Missing Anti-Clickjacking Header
- CSP Header Not Set
- Information Disclosure Issues

## Outcome

Successfully completed a vulnerability assessment using OWASP ZAP, documented the findings, and provided security recommendations based on the identified vulnerabilities.
