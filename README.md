# OWASP ZAP Vulnerability Assessment

This repository contains the work completed for Future Interns – Cyber Security Internship Task 1.

## Project Objective
To perform a vulnerability assessment on a web application using OWASP ZAP, identify security vulnerabilities, analyze their potential impact, and recommend appropriate security measures.

## Target Website
- demo.testfire.net (Test Website)

## Tools Used
- OWASP ZAP
- Google Chrome
- GitHub

## Repository Structure
- Report/ – Final vulnerability assessment report.
- OWASP_ZAP_Results/ – Auto-generated OWASP ZAP report and supporting screenshots.

## Outcome
The assessment identified multiple security vulnerabilities, including Cross-Site Scripting (XSS), missing security headers, and Cross-Site Request Forgery (CSRF)-related issues. Recommendations have been provided to improve the application's overall security posture.
