# OWASP ZAP Results

This folder contains the raw results generated during the OWASP ZAP vulnerability assessment.

## Contents
- OWASP ZAP Vulnerability Assessment Report.html – Auto-generated scan report.
- s1.jpeg – OWASP ZAP interface before scanning.
- s2.jpeg – Target website (demo.testfire.net).
- s3.jpeg – OWASP ZAP scan results.
- s4.jpeg – Detected security alerts and vulnerabilities.

These files provide evidence of the vulnerability assessment performed on the target web application using OWASP ZAP.
